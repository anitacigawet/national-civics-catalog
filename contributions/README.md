# Historical source evidence

This directory preserves evidence packets created for source changes before the repository closed external contributions:

```text
contributions/<state-code>/<source-id>/<github-login>-YYYY-MM-DD.json
```

Each packet records the canonical source object, the change type, the authenticated maintainer account, disclosed AI tools, and a short factual evidence note. It contains no meetings, copied documents, transcripts, personal information, credentials, or parser code.

These packets are retained as historical provenance. No new public submission path is available, and future catalog maintenance uses trusted maintainer batches.
