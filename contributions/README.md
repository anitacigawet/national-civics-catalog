# Contribution evidence

Each accepted source change keeps a small evidence packet here:

```text
contributions/<state-code>/<source-id>/<github-login>-YYYY-MM-DD.json
```

The packet records the proposed canonical source object, whether it fills a preformed record, adds a genuinely missing body, or corrects an existing source, the contributor's GitHub login, disclosed AI tools, and a short factual evidence note. It contains no meetings, copied documents, transcripts, personal information, credentials, or parser code.

See [`../contribute/AI-INSTRUCTIONS.md`](../contribute/AI-INSTRUCTIONS.md).
